- chat-prompt-templets -
        A ChatPromptTemplate is a reusable, fill-in-the-blank message structure used to talk to AI chat models (like in LangChain Core Reference).
    Think of it like a script or a form letter: instead of writing a whole new conversation setup from scratch every time, you create a fixed pattern with empty slots (placeholders) that get filled with new data automatically.
    It organizes messages by roles—such as:
    • System: Setting the AI's personality or rules ("You are a helpful assistant named {name}").
    • AI / Human: Storing past chat turns or history.
    • User Input: The live question coming from the user ("{user_input}").

    Prompt template for a language model.

A prompt template consists of a string template. It accepts a set of parameters from the user that can be used to generate a prompt for a language model.

The template can be formatted using either f-strings (default), jinja2, or mustache syntax.

-  Pydantic - 
                Pydantic in Generative AI (Gen AI) acts as a strict data validation, structuring, and type-safety layer between unpredictable Large Language Models (LLMs) and reliable application code.

                Pydantic is a security guard and rulebook for Generative AI. It makes sure that messy, unpredictable text coming out of an AI model matches an exact, clean shape your computer program can trust

                BaseModel or TypeAdapter. It tells your code what structure, data types, and validation rules incoming or outgoing data must follow.
